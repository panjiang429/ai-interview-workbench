# AI 面试准备工作台 (Interview Workbench)

一个用 AI 全程搭建的**面试准备一体化工作台**：把个人资料拆解成可背诵的面试内容、按岗位方向组织讲法、面试前 AI 押题生成分段讲稿、面试后 AI 复盘分析。

> 本仓库为**静态演示版**：个人区使用脱敏示例数据（公司/学校/姓名已替换为占位符），AI 生成与云保存功能已关闭。完整版支持云端数据库、账号隔离与实时 AI 生成。

## ✨ 功能

### 1. 题库总库（438 题 · 14 大类）
- 自我介绍 / 宝洁八大问 / 行为面 / HR 深挖 / 情景压力 / 群面 / Case 面与商业实战 / 数据岗硬技能（SQL·统计·指标体系）/ **AI 时代面试专项（工具·认知·落地·产品·伦理·发展）** / 行业专项 / 简历深挖链 / 分轮次 / 英文面试
- 每题含：分段时间讲稿（随计时自动高亮）、英文版、追问应对、常见坑、评分锚点（bad/ok/good 三档）、难度星级、变体问法
- 二级子分类导航 + 全文搜索 + 时长筛选 + 计时练习

### 2. 个人素材卡（STAR 拆解）
- 每段经历拆成 S/T/A/R + 适用题型 + 被追问风险 + **深挖问答**（面试官大概率追问的 Q/A）
- 每条内容标注证据来源，不编造

### 3. 岗位方向讲法
- 同一段经历按 9 个方向（商分/运营增长/AI 产品/项目管理/金融研究/供应链/管培/品牌营销/咨询研究）给出不同讲法
- 每个方向含：面试官视角、答题主线、高频问答、短板与补法、英文定位、考前 48 小时清单

### 4. AI 押题（完整版）
- 输入公司 + 岗位 + JD → AI 联网检索出题单（分必考/大概率/防身三档）→ 逐题生成 **5 分钟分段长稿**
- 每题可一句话让 AI 按你的真实经历重写，旧版本保留可回退
- 复盘数据自动回流：上次被问倒的题型，下次押题强制布防

### 5. 面试复盘
- 结构化录入（轮次/被问倒的题/AI 面试环节/教训）→ AI 横向分析历史复盘，找重复失分模式

### 6. AI 面试应对
- AI 视频面 / AI 文本测评 / AI 简历初筛四种形式的打法与评分维度

## 🛠 技术实现

- **纯前端静态站**：单页 HTML + 原生 JS，题库为静态数据文件，秒开、可离线
- **云数据库**（完整版）：PostgreSQL + 行级安全（RLS），个人数据 owner-only，多设备同步
- **AI 引擎**（完整版）：云端 LLM 免密钥调用；两阶段生成（题单 → 长稿）；提示词中注入候选素材卡并强制"禁止编造经历"约束
- **个人区同步**：SECURITY DEFINER 函数首次登录自动灌入模板

## 🚀 本地运行

无需构建，直接打开 `index.html` 或起一个静态服务器：

```bash
npx serve .
# 或
python -m http.server 8080
```

## 📁 目录结构

```
index.html      主页面（结构 + 通用内容 + 个人区渲染）
theme.css       主题样式
engine.js       题库引擎（导航/搜索/计时练习/评分锚点）
predict.js      AI 押题引擎（题单 + 长稿两阶段）
revise.js       全站"按你的话改"修改引擎（版本历史/回退）
q1–q13.js       题库数据（438 题）
demo-data.js    演示模式示例数据（已脱敏）
```
